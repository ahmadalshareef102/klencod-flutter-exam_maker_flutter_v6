# صانع الاختبارات الذكي (Flutter)

## قبل البناء
1. الخطان في assets/fonts مؤقتان (DejaVu Sans بأسماء Cairo)؛ استبدلهما بملفي Cairo الحقيقيين بنفس الاسمين متى شئت.
2. ارفع المشروع إلى Klencod/GitHub؛ مجلد android مضمّن (Gradle 8.14 + AGP 8.11.1 لـ Flutter 3.47).

## المرحلة الحالية
- محرر الأسئلة + قوالب جاهزة + شريط رموز رياضية
- ترويسة رسمية قابلة للتعديل، عمودان، ورقة طالب / نموذج إجابة محلول
- استيراد كشف الطلاب من Excel (ورقة مستقلة لكل طالب + QR)
- ورقة تظليل OMR
- التصدير: PDF (طباعة / حفظ / مشاركة)

- كيبورد الرياضيات: كسور، جذور، جمع/طرح/ضرب عمودي، أرقام عربية ورموز (مع معاينة حية، وتظهر في PDF)

- التصحيح الآلي بالكاميرا لورقة OMR (أيقونة الماسح في الأعلى): يجب إدخال مفتاح التصحيح (أ,ب,ج,د...) من إعدادات OMR
- تصدير Word (كسور وجذور كمعادلات)

## ملاحظات OMR
اطبع الورقة بمقاس A4 100% بدون تكبير/تصغير، وصوّرها كاملة بحيث تظهر المربعات السوداء الأربعة في الزوايا.

## المرحلة القادمة
- التفعيل بمفتاح، تصدير نتائج OMR إلى Excel، قراءة QR لتحديد الطالب تلقائيا
